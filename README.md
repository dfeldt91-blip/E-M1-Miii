Welcome to the E-M1 Miii Mod Builder

This is a Mac and Windows program that allows a user to create a custom modded firmware for their E-M1 Miii camera. It works by downloading the official Version 1.6 firmware from Olympus, allows a user to select mods, then creates a modded firmware and gives instructions for install. It also allows you to download the official stock version 1.6 firmware if you would like to go back to stock.

I do not own and cannot make mods for other models, unless you want to send me a camera to test on. If you want custom firmware for your camera, you can check what is available here:
https://xulfr.github.io/om-firmware-atlas/views/cameras/

When I started this project, I just made changes I wanted for my camera, so they were all over the place.
Going forward I will be making large pushes for specific feature sets. For example, the next release might focus specifically on modifications to the focus system, while the one after might focus on Art Filters, while a third might focus on Video.

My CURRENT FOCUS is on the ART Filter system. My goal is to remove the current ART Filters and enable more slots, each of which is either a color or monochrome base, with settings to enable/disable/alter vignette/grain/gradation/saturation/etc per filter slot. This would essentially give you the ability to create your own looks in camera - I, and a lot of others, don't like to edit on a computer so this is for us!

The LATEST VERSION has a new UI and includes:
- Tone Curves: Large selection added to Gradation Menu
- Tone Curves: Two Configurable Custom slots via app
- Handheld High Res Mode: Manual and Fill Flash (TTL lens required)
- Aspect: Xpan 65:24
- White Border: Effect added for Art Filters (can set the border width in program)
- Focus Stacking: In-camera, w/ all lenses
- Auto-ISO: Starts at ISO64 vs ISO200
- Video: Recording limit removed
- Custom C1/2/3/4: Save Video modes
- Art Filter: Monochrome Key Lines II
- Custom Buttons: Options increased for right and down buttons
- 6 Selectable Filter Slots assigned to Custom Picture Profile
- Underscore is now an option for custom filename
- Text can be set at top of first menu page (I use for Name/Phone if lost/stolen, survives factory reset)
- Digital Teleconverter in Hi Res Mode. Best results with Sharpness set low.
